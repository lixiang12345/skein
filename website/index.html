Start with your existing relay

From install to first task.

Skein stores the credential environment-variable name—not the credential—in connection metadata.

1 · Install
# Node.js 22.16 or newer
npm install -g @skein-code/cli
skein --version
# Export your relay key, then reference its name.
export TEAM_RELAY_API_KEY=…

skein agents setup --yes \
  --name team-relay \
  --provider compatible \
  --protocol openai-responses \
  --base-url https://relay.your-company.test/v1 \
  --api-key-env TEAM_RELAY_API_KEY \
  --model provider/coding-model
# Open the TUI in any repository.
cd your-project
skein

# Or use the stable headless contract.
skein -p --output-format json "Find and fix the parser bug"

Official account login is intentionally out of scope. Primary connections use explicit third-party or local relay contracts.

Straight answers

Before you install.

Does Skein send my repository to a retrieval service?+

No. The default code index is local and offline-capable. Model prompts still contain the context selected for the configured model endpoint, so your relay's data policy remains important.

Which model providers can I use?+

Skein supports OpenAI Responses, OpenAI Chat, Anthropic Messages, Gemini, and compatible relay connections. Each protocol and authentication header is selected explicitly.

Can Skein run in CI?+

Yes. Print mode supports text, JSON, and streaming JSON. Final status and exit codes distinguish verified, unverified, failed, cancelled, and incomplete work.

Can the model bypass denied tools?+

No. Tool categories, command rules, workspace boundaries, and completion checks are enforced by the runtime outside model output.

How do external coding CLIs fit in?+

Installed Codex, Claude, or Grok CLIs can act as bounded read-only experts. External writer access is not silently enabled; writable delegation stays behind Skein's reviewed API writer lane.
