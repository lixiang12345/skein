⌁ SKEIN · THEME LAB

终端 UI 主题实验室

五个完整方向，每个终端自动循环播放三幕：进入（索引准备 → 品牌横幅）→ 运行（状态词 / 工具调用 / 失败重试 / 流式回复）→ 收尾（验证回执 → 就绪）。可用「重播」重看，注意底部状态栏、工具行图标与运行状态词的差异。

已定方向：状态词采用 Skein「织线」隐喻——Gathering threads（取上下文）→ Spinning（思考）→ Weaving the reply（写回复）→ Tying off（收尾验证）。每个词固定映射一个真实阶段，可预测、有品牌性；方案 C 保留了 Claude Code 式随机趣味词供对比。差异轴：色系 × spinner 动效 × 工具行状态（成功沉默 vs 状态灯）× 状态词策略。

图标语义体系（全方案共享）

一个图标只承载一种含义；成功的工具行保持沉默，颜色只出现在需要注意的地方。
